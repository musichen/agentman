# Agentman v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a colourful, mouse-capable local terminal UI for managing sessions from seven installed coding agents.

**Architecture:** `agentman` is a single Rust binary with a Ratatui/Crossterm UI over a small adapter module. Adapters discover only their own files, normalize records into `Session`, build verified native launch commands, and use atomic metadata rewrites or Trash moves only where the native CLI does not support the action.

**Tech Stack:** Rust 2024 (MSRV 1.88), Ratatui 0.30, Crossterm 0.29, Serde/JSON, `trash`, `fuzzy-matcher`, `anyhow`, and `tempfile` for tests.

**Spec:** `docs/superpowers/specs/2026-09-09-agentman-design.md`

## Global Constraints

- Support Codex, Claude Code, OpenClaude, Pi, Codewhale, DSH, and ACRYL in v0.1.
- Never show or log a token, prompt body, or session message content.
- Prefer each agent's local CLI; otherwise use only storage-aware atomic edits.
- Send deletions to macOS Trash only, after explicit confirmation.
- Preserve terminal state around child interactive processes.
- Include the supplied logo as `assets/agentman-logo.png`; do not depend on terminal image protocols.
- Release under MIT; do not commit credentials or user-specific paths.
