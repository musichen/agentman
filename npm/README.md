# agentman-cli (npm)

The npm distribution downloads the matching GitHub release binary for macOS ARM64, Windows x64, Linux x64, or Linux ARM64 during install. The global command is `agentman`.

```bash
npm i -g agentman-cli
agentman
```

Also published as the scoped alias [`@webboxescom/agentman`](https://www.npmjs.com/package/@webboxescom/agentman) (`npm i -g @webboxescom/agentman`). The bare `agentman` name is reserved by npm's name-similarity policy and cannot be registered.
